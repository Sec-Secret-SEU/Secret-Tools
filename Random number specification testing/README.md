# 🎲 随机数规范测试程序

## 📘 项目简介

本项目是一个用于 **随机数质量检测** 的程序，实现了多种随机性检验算法。
程序提供了直观的图形用户界面（GUI），支持：

* 直接输入二进制序列
* 从文件导入序列
* 随机生成二进制序列

并对输入序列进行随机性检验，输出详细结果。

---

## ✨ 功能特点

* ✅ 支持随机生成二进制序列并保存到文件
* 📂 支持从文件导入二进制序列进行检测
* 🧮 实现多种国际标准的随机性检测算法
* ⚙️ 用户可选择性地执行特定检测方法
* 🕒 实时显示检测结果（是否通过、P值、Q值、检测耗时）
* 🔍 自动验证输入序列的有效性（仅包含 `0` 和 `1`）

---

## 🧠 检测算法

程序实现了以下随机性检测算法：

| 检测算法                                              | 说明                           |
| ------------------------------------------------- | ---------------------------- |
| **单比特频数检测（Monobit Frequency Test）**               | 检测序列中 0 和 1 的比例是否接近 1:1      |
| **块内频数检测（Block Frequency Test）**                  | 将序列分成若干块，检测每块中 1 的比例是否接近 0.5 |
| **扑克检测（Poker Test）**                              | 检测各种长度为 *m* 的子序列出现频率是否符合随机分布 |
| **游程检测（Runs Test）**                               | 检测序列中游程数量和分布是否符合随机性          |
| **块内最大游程检测（Longest Run of Ones in a Block Test）** | 检测各块内最长连续 1 的长度是否符合预期        |
| **近似熵检测（Approximate Entropy Test）**               | 衡量序列复杂性，检测新子序列出现的速率          |
| **重叠子序列检测（Serial Test）**                          | 检测相邻子序列之间的相关性                |
| **自相关检测（Autocorrelation Test）**                   | 检测序列与自身平移后的序列之间的相关性          |
| **二元推导检测（Binary Derivative Test）**                | 对序列进行二元运算后再检测随机性             |

## 🚀 使用说明

### 启动程序

运行主界面文件：

```bash
python mainUI.py
```

### 操作步骤

1. **输入二进制序列**（三种方式）：

   * ✍️ 直接输入：在右侧文本框中手动输入序列
   * 📁 从文件导入：点击「选择文件」按钮，导入包含二进制序列的 `.txt` 文件
   * 🎲 随机生成：点击「随机生成」按钮，输入所需序列长度

2. **选择检测方法**
   在左侧勾选需要执行的检测算法（支持多选）

3. **执行检测**
   点击「计算」按钮开始检测

4. **查看结果**
   检测结果将显示在下方文本框中，包括：

   * 检测是否通过
   * P 值
   * Q 值
   * 检测耗时

---

## 📊 检测原理

所有检测基于统计学 **假设检验（Significance Test）**，显著性水平设为 **α = 0.01**。
当检测得到的 **P 值 ≥ α** 时，认为序列通过随机性检测。

---

## ⚠️ 注意事项

* 输入序列应 **仅包含 0 和 1**
* 序列过短可能导致检测结果不准确
* 随机生成的序列会自动保存到指定目录，文件名以生成时间命名
